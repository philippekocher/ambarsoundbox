# Examples

Example patches for AMBAR Soundbox.

Since this is content rather than code, it's intentionally excluded from this repository (see [.gitignore](../../.gitignore)). If you run your own instance, you can add your own examples as needed. If you want your examples committed in your own fork/clone, change the `.gitignore` file accordingly.


## Add an example

1. Drop a new `.json` patch file into this folder.
2. Rebuild (`npm run dev` / `npm start` / `npm run build`) — new examples are picked up automatically.
